# 异常处理的数据安全边界

下一步：凡是涉及丢数据、串角色、重复扣费、导入恢复或清理，先停止写入并做备份，再继续排查。

## 可以优先尝试的低风险动作

1. 记录版本、模块、状态码和第一句错误。
2. 使用短文本、小图、短音频或测试条目做一次最小复现。
3. 切换稳定网络，重新打开当前页面。
4. 临时停用刚启用的美化 CSS 或插件。
5. 检查角色、会话、可见范围、Provider 和模型是否选对。
6. 查询原任务或订单状态。
7. 导出当前完整备份，并在系统文件管理器核对文件。

## 必须先备份再做的动作

- 导入完整备份或角色数据迁移。
- 图片压缩、聊天冷归档、删除已消化图片。
- 大批量导入表情包、3D 资产、主题、角色卡或插件。
- 修改世界书、身份、预设和重要记忆等会改变主聊天提示词的内容。
- 恢复默认外观之外的大规模 CSS 替换。

## 首轮排查禁止建议

- 清除浏览器站点数据、IndexedDB、localStorage 或全部缓存。
- 删除角色、聊天、记忆、相册、订单或任务记录。
- 导入旧备份覆盖当前状态。
- 重复提交状态未知的生成、支付、上传和恢复任务。
- 将完整 API Key、Cookie、Authorization、备份或私人媒体发给客服/机器人。

## 立即升级开发者的情况

- 选择正确仍出现串角色、串会话或越权可见。
- 页面提示保存成功但刷新稳定丢失。
- 单次点击稳定发出多个请求、重复下单或重复扣费。
- 导入预览写入目标与实际目标不一致。
- 恢复完整备份后稳定漏掉同一类数据。
- 默认主题、无插件时仍白屏或核心按钮无响应。
- 外部服务最小测试正常，只有眠眠机稳定失败。

升级材料只包含：应用版本、平台、模块、完整操作步骤、发生时间、状态码/错误名、脱敏第一句错误、最小测试结果和最近一次相关改动。

## 应联系服务商的情况

- Key/权限确认无误仍返回 401/403。
- 余额和套餐正常仍返回 402。
- 降低频率后仍持续 429。
- 最小短请求持续返回 5xx、504/524 或 CDN 520–526。
- 服务商控制台中的异步任务长期无终态。
- 服务商文档支持的模型、文件格式或参数仍被接口拒绝。

联系服务商不代表可以发送 Key。只提供服务商、模型/功能、状态码、发生时间和脱敏错误摘要。
