# 什么时候联系开发者

下一步：先完成对应模块文档里的“现在做”步骤，并保留第一条脱敏错误。

## 联系 API 服务商

联系服务商的情况：

1. 401 或 403，且密钥和权限需要服务商处理。
2. 429 持续存在，需要调整额度或并发限制。
3. 5xx 在服务商状态页也存在。
4. 其他客户端使用同一配置也失败。

## 联系 IDIC.Chat 开发者

联系开发者的情况：

1. 配置和服务商都正常，但只有 IDIC.Chat 稳定复现。
2. 页面、设置、IndexedDB 或本地保存稳定失败。
3. 请求成功，但 IDIC.Chat 无法解析或显示结果。
4. 出现疑似数据丢失、错误迁移或重复生成。
5. 按文档操作后问题仍可稳定复现。

## 当前联系方式

项目没有在源代码和公开文档中确认开发者联系方式。机器人必须使用部署方配置的联系方式，不能自行编造邮箱、QQ群或其他账号。
