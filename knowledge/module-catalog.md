# 眠眠机（Mmianji）AI 问答知识库目录

下一步：先让用户说出“在哪个页面、做了什么、看见什么提示”，再给一个两分钟内能完成的最小检查。不要先让用户清数据、重装、换 Key 或把所有设置改一遍。

## 回答规则

1. 先给结论：问题属于配置、模型服务、本地数据、显示层、权限，还是正常功能边界。
2. 再分诊：同一句“不能用”在私聊、生图、STT、TTS、音乐、电影和视频里可能是完全不同的 API。
3. 先给一项最小动作，再给后续排查；避免让用户并行修改多项设置。
4. 说明数据影响：操作会写聊天历史、角色记忆、条件式提示词、角色配置，还是完全不自动影响。
5. 收集错误时只要状态码、第一句错误、功能入口、模型/服务类型和发生时间；禁止索取 Key、Cookie、完整请求体、聊天正文或私人媒体。
6. 不确定时明确说“不确定”，继续追问版本、入口、目标角色和第一条脱敏错误，不猜按钮或后台行为。

## API 与主聊天影响的统一判断

- **角色主 API**：该角色专属聊天线路；未覆盖时使用全局主 API。用于私聊和需要保持角色人设的台词。
- **主 API**：全局默认聊天线路。
- **副 API 1**：偏复杂分析、整理、关系、查手机、购物等辅助任务；不是所有模块都会回退主 API。
- **副 API 2**：偏轻量分类、NPC、环境、素材或策略任务。
- **独立服务**：生图、STT、TTS、网易云、原创音乐、天气、实时视频、COS 等与主聊天线路分开。

App 内容影响角色主聊天有五条路径：直接写进聊天历史、写进角色记忆、按角色/话题注入提示词、改变角色配置，或完全不自动影响。模块“调用了 AI”不等于结果一定进入主聊天；内容“进入背景”也不等于角色下一句一定主动复述。

## 两套记忆先分清

- **本地角色记忆库**：入口在角色设置“打开记忆库”；可选的“设置 → 记忆向量 API”只增强模糊语义召回。数据主要保存在当前浏览器本地。
- **海马体**：入口在“设置 → 海马体记忆系统”；数据在用户自己的 Supabase 项目，需要独立部署和配置，并且还要给具体角色开启。
- **近期上下文**：只是在每次模型请求中携带的最近消息，不是永久记忆。把条数调到最大只会更慢、更耗 token，不能替代长期记忆。
- **我的身份**：当前会话中“用户是谁”的稳定资料；侧栏个人资料不一定会自动代替它。
