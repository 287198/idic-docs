# 查日志和提交脱敏信息

下一步：在复现问题前打开开发者工具的 Console。

## 网页版

1. 按 `F12` 打开开发者工具。
2. 打开 `Console` 标签。
3. 清空旧日志。
4. 只复现一次问题。
5. 复制第一条相关错误和前后少量日志。

需要看请求时：

1. 打开 `Network` 标签。
2. 重新执行一次失败操作。
3. 找到失败请求。
4. 只记录状态码、失败阶段和时间。

不要复制完整请求头、完整请求体或全部聊天记录。

## 常见日志关键词

- 聊天：`[IDIC][ChatCore]`、`AI-DIAG`、`API请求失败`
- 群聊：`[群聊API]`
- 记忆：`[IDIC][Memory]`、`memory`、`recall`、`embedding`
- 海马体：`[Hippocampus]`、`dehydrate`、`auth`
- 数据：`IndexedDB`、`数据库初始化`、`数据保存`
- 音乐：`播放器大脑`、`歌曲缓存`、`歌词`
- 天气：`Weather`、`天气系统`
- 宠物：`宠物调试`、`宠物意愿`

## 先判断错误属于哪一类

1. 有 HTTP 状态码：先按 API 服务商错误处理。
2. 有 `Failed to fetch` 或 CORS：检查网络、代理和地址。
3. 有 `IndexedDB`：先停止删除和迁移操作，联系开发者。
4. 请求成功但页面解析失败：通常需要联系开发者。
5. 只有浏览器权限错误：先处理麦克风、摄像头或存储权限。

## 粘贴日志前必须删除

- API Key 和 `Authorization`。
- Cookie、Token、绑定码和用户 ID。
- 完整 API 地址中的私有域名。
- 聊天、角色、世界书、记忆和日记正文。
- 联系人、位置、钱包和图片私人地址。

最后一步：只提交“版本 + 模块 + 操作 + 时间 + 第一条脱敏错误”。
